\# Secure Online Voting System



A secure web-based online voting system designed to provide a simple and reliable method for conducting elections digitally.



\## Features



\- Secure voter login

\- OTP-based voter verification

\- Electoral roll validation

\- One-person-one-vote validation

\- Blockchain-based vote recording

\- Tamper-evident vote chain

\- Admin dashboard

\- Election result display

\- Invalid login and OTP handling

\- Vote status tracking

\- Candidate images and information



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- JavaScript

\- Blockchain

\- CSV
